## 🚀 Quick Start

### 1. Activate Virtual Environment
```bash
# Windows
env\Scripts\activate

# macOS/Linux
source env/bin/activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run Application
```bash
python app.py
```

### 4. Open Browser
```
http://localhost:5000
```
